Política de privacidade

Esta página explica quais dados podem ser processados quando você usa o Riff Theory e quais ficam apenas no seu navegador.

Prática, preferências e tablaturas

Preferências de instrumento, escala, progresso local e rascunhos são armazenados no navegador. Esses dados não são enviados para uma conta pela aplicação.

Assistente Thonic

Quando você entra e envia uma pergunta, o texto e o histórico recente são enviados ao serviço de IA para gerar uma resposta. A interface informa esse fluxo antes do uso.

Monitoramento de acessos

O monitoramento é opcional. Se você permitir, usamos um identificador aleatório e pseudônimo para contar entradas e sessões. O Riff Theory não coleta nem armazena IP para criar esses registros. A verificação antirobô do Cloudflare pode processar dados técnicos durante o desafio.

Como recusar ou revogar

Você pode recusar na barra de consentimento. Para revogar uma autorização anterior, apague os dados do site no navegador. Recusar não impede o uso das ferramentas.
