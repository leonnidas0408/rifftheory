Como usar

Escolha o BPM, selecione o compasso e pressione iniciar. O primeiro tempo recebe um acento para ajudar você a se localizar.

Para que serve

Use andamentos baixos para trocar acordes com precisão, aumente gradualmente quando a execução ficar limpa e pratique escalas, levadas e tablaturas.

Áudio local

Os cliques são gerados pela Web Audio API após uma ação sua. O metrônomo não precisa de cadastro nem envia o áudio da prática.

Perguntas frequentes

  • Funciona no celular? Sim, a interface é responsiva.
  • Precisa criar conta? As ferramentas abertas podem ser testadas sem cadastro.
  • O acesso é gratuito? As ferramentas públicas são gratuitas; o Thonic tem regras próprias.
