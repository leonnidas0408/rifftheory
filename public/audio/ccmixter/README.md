# Amostras reais de violão

As amostras de acordes desta pasta foram baixadas do pacote **12 String guitar samples**, de Stefan Kartenberg (ccMixter), e são usadas para reprodução local na área Prática.

- Fonte: https://ccmixter.org/files/JeffSpeed68/52387
- Licença: Creative Commons Attribution-Noncommercial 3.0 (CC BY-NC 3.0)
- Autor: Stefan Kartenberg (perfil ccMixter: JeffSpeed68)
- Arquivos originais: os ZIPs `JeffSpeed68_-_12_String_guitar_samples.zip` e `JeffSpeed68_-_12_String_guitar_samples_1.zip`

Os arquivos foram renomeados apenas para organizar os acordes maiores e menores usados pela aplicação. Acordes sem amostra específica continuam usando o áudio sintético de fallback.
