TabMaker: o que é e como criar uma tablatura

TabMaker é o nome dado a uma ferramenta para escrever ou editar tablaturas — uma forma de representar posições e técnicas no instrumento sem exigir que a pessoa leia partitura tradicional. O criador de tablatura do Riff Theory abre uma grade editável de seis cordas, cria uma prévia em texto e permite copiar ou baixar o resultado. É um editor manual: você escreve as notas e decide o que quer registrar.

Como ler as linhas e os números

As seis linhas representam as cordas. Na convenção mais comum, a linha de cima é a corda mais aguda e a de baixo é a mais grave. No editor, os rótulos aparecem de cima para baixo como e, B, G, D, A, E; ao lado deles, a afinação mostra as notas correspondentes. Cada número indica a casa a pressionar naquela corda: 0 significa corda solta, 1 a primeira casa, e assim por diante.

Números alinhados verticalmente na mesma posição indicam notas para tocar juntas, como uma forma de acorde. Uma sequência que avança para a direita representa o desenrolar da tablatura. Células vazias aparecem como traços de preenchimento na prévia: elas mantêm a posição alinhada, mas não indicam uma casa pressionada.

Escreva e revise uma tab no editor

  1. Abra a ferramenta e dê um título ao rascunho, se quiser identificar o exercício.
  2. Escolha um dos presets disponíveis: afinação padrão, Drop D ou meio tom abaixo. O nome da nota junto à corda muda para acompanhar o preset.
  3. Digite em cada célula uma casa de 0 a 24. Deixe a célula vazia quando não quiser registrar uma nota nessa posição. Notas na mesma coluna ficam alinhadas na prévia.
  4. O compasso inicial tem oito posições. Use “+ Compasso” para ampliar a grade; remover compasso retira o último, mantendo pelo menos um.
  5. Confira a prévia textual. Use “Copiar” para a área de transferência ou “Baixar .txt” para salvar um arquivo local.

O editor reconhece marcadores de técnicas comuns: h hammer-on, p pull-off, b bend, r release, ~ vibrato, / e \ slides, t tapping e x nota abafada. Por exemplo, 5h7 representa uma sequência de casa e hammer-on; escreva o token e os números de destino conforme necessário.

O que o editor salva — e o que não faz

O rascunho é guardado no armazenamento local do navegador usado naquele dispositivo e perfil. Não é sincronizado entre dispositivos. Se o armazenamento estiver indisponível, copie ou baixe seu texto para evitar perdê-lo. A exportação é texto simples; o editor não grava áudio, não reproduz a execução, não importa uma música e não gera tablaturas automaticamente.

Uma tablatura também não costuma indicar sozinha a duração exata de cada nota, a dinâmica ou a digitação mais confortável. Use sua escuta e o contexto musical para interpretar o ritmo e confira se a afinação indicada corresponde ao instrumento.

Perguntas frequentes

TabMaker e tablatura são a mesma coisa?

Tablatura é a notação de posições no instrumento; TabMaker é uma ferramenta para criar ou editar esse tipo de notação.

Posso colocar uma casa maior que 24?

Não neste editor: as casas aceitas vão de 0 a 24. Se precisar de outro registro, a grade não consegue representar essa casa.

O rascunho aparece em outro aparelho?

Não. O rascunho fica salvo no navegador atual, sem sincronização entre dispositivos. Baixe o arquivo ou copie a prévia para transferi-lo.

O editor toca a tablatura para mim?

Não. Ele monta a representação textual para você copiar ou salvar, mas não reproduz as notas nem transforma uma música em tab.

Posso escrever uma afinação personalizada?

Os presets atuais são padrão, Drop D e meio tom abaixo; não há campo para cadastrar uma afinação arbitrária.
